# ADR-004: 市場補正型の単勝確率モデルを予測MVPに採用する

- Status: Superseded
- Date: 2026-10-03
- Decision Owners: Repository maintainers
- Supersedes: N/A
- Superseded by: [ADR-009](ADR-009-use-lambdarank-mvp-and-top3-pl-extension.md)

## Context

[要件定義](../requirements.md)はJRA平地重賞を評価対象とし、発走前の同じ判断時点の市場オッズより良い確率推定を目指す。開発順はデータの時点監査、市場基準、教師ありの着順確率・分布、買い目と購入額の最適化である。手元の原本に発走前オッズ履歴があるかは未確認であり、購入案の提示期限は発走5分前である。

提供された調査レポート「競馬予測における確率モデル・機械学習モデルの研究・実装動向調査」は、市場確率を補正する構成と、CatBoost/LightGBMの能力スコアからPlackett–Luceの着順分布を作る構成を推奨する。ただし、[CatBoost Rankerの比較研究](https://doi.org/10.5351/KJAS.2024.37.2.239)は韓国競馬の順位予測を評価したもので、JRAの単勝確率の校正や回収率の優位を示していない。[Benterの研究](https://gwern.net/doc/statistics/decision/1994-benter.pdf)は、同じ強さで2・3着を逐次選ぶHarville型の確率に系統的な偏りがあることを示す。標準的なPlackett–Luceを連勝式へ無検証で適用できない。

## Decision

1. **予測MVPは単勝確率に限定する。** 入力固定時刻までに受信した、同一レースの発売対象馬と単勝オッズの完全なスナップショットを使う。この時点で発売対象の馬 `i` について `q_i = (1/O_i) / Σ_j(1/O_j)` を市場基準として作る。有限で正のオッズ、発売対象馬、受信時刻を確認できないレースは予測・購入評価へ入れない。入力固定後の取消・除外を、過去の予測の分母へ反映しない。`q_i` は市場の基準値であり、真の勝率とはみなさない。
2. 最初の学習モデルは `p_i = softmax_i(log q_i + βᵀx_i)` とする。`x_i` は入力固定時刻までに利用可能だったことを確認できる少数の特徴量に限る。係数は過去レースの勝者についてレース単位の対数損失を最小化し、正則化の強さと特徴量は内側の時系列検証で決める。学習に使う着順ラベルも、単独勝者が定まり入力固定後に発売対象馬が変わらなかったレースに限る。これは市場を補正する条件付き多項ロジットで、レース内の勝率合計が1になる。
3. 校正が必要なら、内側の検証期間だけでレース単位の温度を推定し、全馬の確率を再正規化する。馬ごとの独立した校正で総和1を崩さない。校正の採否も保留評価期間を見る前に決める。
4. MVPの購入案の対象は**単勝のみ**とし、購入しない選択を含める。七券種は要件どおり初期の調査・比較対象に残す。買い目・購入額の実運用ルールは、当時のオッズと払戻、オッズ変動、購入経路、リスク尺度を確認してから確定する。それまでは購入提案の実績や回収率を実運用相当と称しない。

## Rationale

市場基準を固定してから補正の増分を測れば、REQ-03の「同じ時点の市場より高精度か」を直接検証できる。小規模なレース内モデルは、確率として学習でき、学習量が限られる重賞の評価にも複雑な順位モデルより過学習を調べやすい。予測MVPの段階で新しいモデル依存を必要としない。調査レポートの `log q_i + g(x_i)` の構成において、まず `g` を線形に限定した選択である。

## Extensibility and Alternatives

- **市場のみ** `q_i` を、学習モデルの必須比較基準とする。オッズ履歴を確認できない期間を、最終オッズで代用しない。
- **CatBoost/LightGBM + Plackett–Luce** は次の比較候補とする。Rankerの生スコアを勝率とは呼ばず、レース内確率化と校正を行い、MVPと同じ時点・レース・指標で比較する。十分な改善がなければ追加しない。
- **複勝・連勝式**へ進む際は、2着・3着の条件付きモデルまたは補正した着順分布を別に学習・検証する。単勝確率だけから標準Plackett–Luceで作った組合せ確率は比較基準にとどめ、券種別の的中条件、同時着順確率、当時のオッズ、払戻を確認してから購入案へ追加する。
- Closing Odds Model、Set Transformer、強化学習、外部予測サービスはMVPに含めない。追加時は時点再現性と保留レースでの増分を確認する。

## Validation / Follow-up

1. オッズ・発売対象馬・特徴量・取消等の発表時刻と受信時刻、着順・払戻、購入可能性を監査する。発走5分前の提示に間に合う入力固定時刻を処理時間の実測から定める。発走前オッズ履歴を再現できない過去期間は同時点市場比較や収益バックテストに使わず、以後の時刻付き保存と観測運用で評価データを作る。
2. 評価はレースを分割単位とする時間順の拡大型Walk-forwardで行う。各外側期間より過去の期間だけで、特徴量、正則化、校正、購入方策を決める。最終の未来期間はモデル選択に使わない。市場基準とMVPは同じ出走馬、レース、入力固定時刻で比較する。
3. **予測モデル採用の主指標**は、勝者のレース単位Log Lossの市場との差とする。レースを単位とした対応ありbootstrapの95%信頼区間を併記し、差の上限が0未満のときだけ市場超過の証拠とする。Brier Scoreは各レースの全馬に対する多クラス値として併記し、確率校正をオッズ帯・予測確率帯・購入候補帯で確認する。単独勝者が定まらない同着と入力固定後に発売対象馬が変わったレースは、単独勝者モデルの主指標から事前規則に従って除き、件数と理由を報告する。これらのレースを結果から黙って消さず、購入方策の評価では確定した精算どおりに扱う。信頼区間が0をまたぐ場合は優位性未確認と報告する。
4. **購入方策は予測モデルと別に評価**する。方策、期待利益の安全幅、損失リスク制限、100円単位の金額、見送り条件は内側の期間で固定する。過去検証では仮想購入額、運用では記録した実購入額を用いて、年10万円・1レース5,000円の上限を判定する。購入判断にはその時点のオッズを使い、事後の確定払戻は精算だけに使う。暦年の券面回収率は `確定払戻・返還に基づく受取額（特払いを含む）÷額面購入額`、純利益は `同受取額−額面購入額−手数料` と定義する。返還も購入済み額面から差し引かず、特払いを通常払戻と重複計上しない。購入額0円の年の回収率は定義しない。手数料が未確認の期間は純利益を確定値として報告しない。購入レース数、的中率、最大ドローダウン、最大連敗、累積純損益の推移と、レース単位bootstrapによる回収率の不確実性を暦年ごとに報告する。累積純損益は年初0円から購入レース順に純利益を積み上げ、最大ドローダウンはその累積値の過去最高値からの最大下落額（円）とする。過去検証の仮想結果と実購入の実績は分けて報告する。年間回収率100%以上は目標であり、単年達成や確率指標の改善だけで利益を保証しない。

## Consequences

予測MVPからは複勝や連勝式の整合した確率をまだ出せない。発走前の時刻付きオッズを確認・蓄積できるまで、市場補正モデルの採用判定と実運用相当の利益評価は保留となる。モデルを実装しても、単勝の購入提案を始めるには購入経路、オッズ変動への安全幅、損失リスク、実購入額の把握方法を別途仕様化する必要がある。

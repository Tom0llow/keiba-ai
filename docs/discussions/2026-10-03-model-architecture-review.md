# 競馬AIのモデルアーキテクチャ案レビュー（2026-10-03）

状態: 設計案。実装済みの構成や採用済みのADRではない。[前回の要件検討](2026-10-02-keiba-ai-requirements.md)で合意した対象・予算・人による購入を前提とする。回収率100%以上は暦年の目標であり、モデルの性能保証ではない。

## 1. 結論と修正が必要な点

提案の「教師あり学習で確率を推定し、市場と比較してから資金配分する」という責務分担は妥当である。以下を修正すると、検証可能な設計になる。

| 提案箇所 | レビューと修正案 |
| --- | --- |
| 勝率をレース内で正規化 | 独立に予測した値を事後的に割る方式では校正が崩れ得る。単独勝者という通常ケースについて、レースを単位とする学習・出力で合計1を満たす。合計1は整合性であり、校正の証明ではない。同着の教師ラベル・精算は別途定義する。 |
| Plackett–Luceで着順分布を生成 | 連勝式には単勝確率から一意に決まらない同時着順確率が必要。Plackett–Luceを最初の比較対象にできるが、2・3着への展開には強い仮定がある。着順段階別、券種別の校正を確認してから購入判断に使う。[Benterの原論文](https://gwern.net/doc/statistics/decision/1994-benter.pdf)は、同型のHarville展開の2・3着確率に偏りを報告している。 |
| `Edge = AI確率 − 市場確率` | 確率差は市場からの乖離を示す診断値にとどめる。購入条件は、発走前に予測した**確定払戻の分布**と購入額から求める期待利益・損失リスクで判定する。JRAのオッズは払戻率を含む概算値で、確定払戻と同一ではない。[JRAの払戻規則](https://www.jra.go.jp/kouza/baken/index.html) |
| Calibration Errorを主要指標に含める | レース単位の勝者Log LossとBrier Scoreを主指標にし、信頼度図とECEは診断に使う。ECEは区間分割や標本数に敏感である。[校正指標の研究](https://arxiv.org/abs/1904.01685) 購入候補に限った校正と、券種別の希少事象も調べる。 |
| T−5分オッズで推論し、T−5分までに提示 | 取得・特徴量生成・最適化・画面表示に時間がかかるため、T−5分ちょうどに初めて届くオッズを使って同時刻までに提示することはできない。提示期限より前に入力を固定し、期限までの処理全体を計測する。 |
| Fractional Kellyで配分 | 単券・固定払戻を仮定した式を、変動する払戻と相関する複数の買い目へそのまま適用しない。着順シナリオごとの損益を用いた離散的な配分を基本案とし、Kelly型は比較候補にする。 |
| 出力を `{買う, 買わない}` とする | これは利用者向けの要約である。内部の出力は買い目ごとの券種・組合せ・金額、参照オッズと取得時刻、見込損益・不確実性、予算残額を持つ。「買わない」は全買い目の金額が0円の場合とする。 |

たとえば、ある単勝の表示オッズが2.0倍、正規化した市場基準確率が0.40、AIの勝率が0.45なら、確率差は+0.05となる。しかし倍率が2.0倍で確定すると**仮定した**100円券の期待払戻は `0.45 × 200円 = 90円` で、期待損失は10円である。この数値例は、実際にはオッズが変動することを省略した説明用の近似である。[JRAの払戻率](https://www.jra.go.jp/kouza/baken/index.html)

## 2. 推奨する責務と確率モデル

```text
購入判断時点までのデータ・各券種のオッズ
    → 時点整合済みの特徴量と市場基準確率
    → 教師ありのレース内確率モデル
    → 必要な券種の的中確率・払戻シナリオ
    → 期待利益と損失リスクを考慮した購入額決定
    → 人向けの提案（人が購入）
    → 実際の購入額・確定払戻・返還の記録
```

### 2.1 単勝から始める場合

同一時点の単勝オッズから得る市場基準値を `q_i`、過去走・当日情報等による補正を `δ_i` とし、初期候補を `p_i = softmax_i(log(q_i) + δ_i)` とする。`δ_i = 0` なら市場基準へ戻り、通常の単独勝者を対象とする勝率の合計は1になる。`q_i` は全馬のオッズ逆数を正規化する等の**推定方法を定義した基準値**であり、`1 / 表示オッズ` を真の勝率と同一視しない。欠損・無効オッズへの対応も学習前に決める。市場の推定と独自モデルを結合する先行例はあるが、JRA重賞での改善は未確認である。[Benterの原論文](https://gwern.net/doc/statistics/decision/1994-benter.pdf)

同じ情報締切で「市場のみ」「過去走等のみ」「市場＋補正」を比較する。補正モデルには小さなレース内ロジットを第一候補とし、木系モデル等は改善を確認してから比較する。市場の入力を使うこと自体は問題ないが、市場のみとの差に加え、AIが市場より高く評価して購入候補とした群の校正を確認する。学習損失・再校正・評価はレース単位で行う。勝率の総和だけでなく、保留期間における予測値と実際の勝率の対応が必要である。

### 2.2 複勝・連勝式へ広げる場合

通常の同着のない結果で、上位3頭の順序付き確率を `P(i,j,k) = P(1着=i) × P(2着=j | i) × P(3着=k | i,j)` と分解する。各段階で候補馬間の確率を正規化すれば、単勝・複勝および馬連・馬単・ワイド・3連複・3連単の的中確率を同一の分布から集計できる。5～7頭立ての複勝は2着まで、8頭以上は3着までという[JRAの発売条件](https://www.jra.go.jp/dento/soku/instructions/pdf/guide_all.pdf?version=202501)を券種計算で反映する。

Plackett–Luceは2・3着も同一の馬の強さから順次選ぶ軽量な基準モデルとする。ただし単勝で校正された確率を展開しても、2・3着や馬券の組合せ確率が校正されるとは限らない。次段階の候補は、2着・3着の選択を別に学習・校正する条件付きモデルである。独立の上位2着・上位3着分類器を使う場合は、各馬の `P(1着) ≤ P(2着以内) ≤ P(3着以内)`、通常レースでのそれぞれの全馬合計 `1, 2, 3`、買い目間の整合性を確かめる。単勝だけを先に公開する段階では、根拠のない連勝式確率を出さない。[Benterの2・3着検証](https://gwern.net/doc/statistics/decision/1994-benter.pdf)

同着があると単独勝者を前提にした分布と実際の的中・払戻の対応が変わる。同着に対応する分布を設けるか、予測モデルの近似範囲と取引制限を明示する。少なくともバックテストの精算では、同着・取消・返還・特払いをJRAの確定結果どおり処理する。[JRAの同着・返還規則](https://www.jra.go.jp/kouza/baken/index.html)

### 2.3 Betting Engine

買い目 `c`、購入額 `x_c`、レース結果・確定払戻を含むシナリオ `ω` に対し、総損益を `G(ω,x) = Σ_c (払戻・返還)_c(ω,x_c) − Σ_c x_c` とする。各買い目は、払戻変動と推定誤差への余裕を引いた後の期待利益が正の場合だけ候補にする。その上で、組み合わせた買い目の `E[G | 判断時点の情報]` と損失側の分布を使って購入額を決める。複勝・ワイドの表示オッズは範囲であり、相手の的中状況で払戻が変わるため、単一の倍率を固定した期待値計算を確定値として扱わない。[JRA-VANの複勝オッズ説明](https://targetfaq.jra-van.jp/faq/detail?category=109&id=436&site=SVKNEGBV)、[JRAの払戻規則](https://www.jra.go.jp/kouza/baken/index.html)

最適化の実行可能集合は、各買い目 `x_c` を100円の非負整数倍、同一レースの `Σ_c x_c ≤ 5,000円`、暦年の**実際の購入額累計＋提案額 ≤ 100,000円**とし、すべて0円を許す。払戻によってこの累計上限は増やさない。複数券種の的中は同じ着順に依存するため、券ごとに独立な損失と仮定せず、シナリオ全体で配分する。目標関数・リスク尺度・安全余裕の数値は未決定であり、学習・検証期間内で選ぶ。一定の確率差だけを購入閾値にしない。

100円刻みは馬券の発売単位だが、利用する購入経路によって一回の最低購入額や手数料は違う。たとえばJRAダイレクトは一回1,000円以上で利用料がある。購入経路を決めた時点で実行可能性と費用に反映する。[JRAの購入経路比較](https://www.jra.go.jp/dento/comparison.html) 人が実際に購入するため、提案額と実購入額を分けて記録し、翌レースの予算残額は実購入額から計算する。

## 3. データ・時刻・推論時間

過去走、血統、騎手・調教師、馬体重、馬場、距離、競馬場等は**候補特徴量**とする。利用可否、発表・受信時刻、欠損率を確認し、過去走の直近N走・条件適性・騎手成績などは各対象レースより前に利用できた情報だけから作る。`N` や集計窓、欠損処理、カテゴリ集計の平滑化も学習期間内で選ぶ。血統や細かな条件別集計は標本が少なくなり得るので、追加価値を比較する。学習対象を重賞だけにするか全平地競走まで広げるかも比較し、**評価対象はJRA平地重賞に固定**する。

オッズの30・20・10分前からの変化、人気順位、投票シェアは、当時取得・保存した系列と各値の発表時刻・受信時刻を確認できる場合のみ使う。手元のJVLinkToSQLite由来DBの[前回調査](2026-10-02-keiba-ai-requirements.md#5-データと検証の成立条件)では時系列オッズ表を確認できず、この特徴量を過去に遡って再現できるとは未確認である。[JRA-VANのデータ仕様](https://jra-van.jp/dlb/sdv/sdk/JV-Data4901.pdf)では単複・馬連の時系列提供期間は1年、その他の速報オッズは1週間である。時系列を取得できない券種・期間は実運用相当の利益検証から外す。Closing Odds Modelは系列保存後の比較実験とし、事後の最終オッズを本体の予測特徴量には入れない。最終オッズの予測も、確定払戻の予測と同じではない。

発走5分前の**提示期限**を `D` とし、入力は `D` より前の処理時間を見込んだ時刻で固定する。各処理で使ったデータの受信時刻、入力固定時刻、提案完了時刻を保存する。発走時刻変更にも対応する必要がある。秒未満のモデル推論は望ましい測定目標だが、合格条件は取得から提示までの全処理が期限に間に合い、人の購入に必要な時間を残すことである。オッズや取消情報が古い・欠けている場合は、その条件で算出した提案を出さず見送る設計を候補とする。JRAの購入経路ごとの締切は[公式比較表](https://www.jra.go.jp/dento/comparison.html)で確認できる。

## 4. 検証と段階的な導入

1. **データ監査と基準方法:** 時点再現性・対象レース・各券種オッズと払戻の保存状況を確認する。市場のみの同時点基準を作る。勝ち馬だけでなく全出走馬を使う。
2. **単勝確率:** 教師ありの市場補正モデルを作り、市場のみ・過去走等のみと比較する。必要なら時系列の別期間でレース単位の再校正を行う。
3. **複勝と連勝式:** まず複勝の的中確率・払戻条件を確認する。七券種は初期の**調査・比較対象**に残し、購入案への投入は各券種の同時着順確率・当時オッズ・払戻の検証が済んだ順に進める。Plackett–Luceは連勝式の基準候補とする。
4. **購入額決定:** 確率と払戻見込みから、見送りを含む買い目別金額を決める。実購入前に観測運用で時刻・オッズ変動・提案と実購入のずれを測る。

学習、特徴量作成、オッズ基準の調整、校正、券種選択、期待値の安全余裕、賭け金パラメータは、いずれも評価対象より過去のレースだけで決める。時系列Walk-forwardの各外側期間を未使用の評価期間とし、調整はその内側の過去期間だけで行う。最終的に別の未来期間を保留する。レースを分割単位とし、同一レースの馬や買い目が学習と評価へ分かれないようにする。[時系列交差検証の解説](https://otexts.com/fpp3/tscv.html)

モデル評価ではレース単位の勝者Log Loss・Brier Score、オッズ帯別と購入候補別の校正、連勝式なら券種別・着順段階別の確率誤差を示す。利益評価は実際の当時の購入可能性と確定払戻に基づき、暦年・券種ごとに購入額、払戻額、回収率、利益、購入レース数、的中率、最大ドローダウン、最大連敗、資金推移を示す。買わない年の回収率は定義しない。標本数、年ごとのばらつき、少数の高額的中への依存と不確実性も併記する。校正やLog Lossが改善しても利益を保証しない。

## 5. 採用を保留する構成と未決事項

- 強化学習は初期の予測・資金配分に不要。将来の連続した購入判断で、明示的な最適化より有利な問題設定と検証結果が得られた場合に再検討する。
- Jevは比較・補助候補にとどめる。確率の整合性、校正、時刻、料金、遅延、再現性を同じ保留期間で測る。モデル比較では確率指標、**全購入方策としての比較**ではROIを使う。JV-Data由来情報を外部APIへ送る前に利用契約を確認する。[Jevの公式仕様](https://docs.typesafe.ai/model-jaggedness/jev-1.13)、[JRA-VANの利用規約](https://jra-van.jp/info/rule.html)
- 期待利益の保守的な見積り方法、払戻変動、複勝・ワイドの条件付き払戻、同着と取消、リスク尺度、年間購入額の配分、実運用へ進むための必要な検証期間は未決定。JRAの特別な払戻率が適用される日もあるため、検証には当時の条件を使う。[JRAスーパープレミアム](https://www.jra.go.jp/kouza/superpremium/)
- 購入経路と利用者向け提案の表示形式は未決定。取引前に、提示オッズの時刻、オッズ変動時の見送り条件、券種・組合せ・金額、推定確率、予算残額を確認できる形を決める。

以上は要件と設計を議論するための案であり、既存の[現行アーキテクチャ](../../ARCHITECTURE.md)やAccepted ADRを変更しない。実装前に、確定した長期的な構成・データ契約を必要に応じてADRに記録する。

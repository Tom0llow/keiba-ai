# 単勝オッズからの連勝式オッズ推定誤差と締切後のオッズ変動

状態: 2026-11-08の読み取り調査。raw、processed、CURRENT、コードは変更していない。
期待値で購入を判断するときに、発走前オッズが保存されていない券種のオッズを、単勝の時系列
から推定して代用できるかを確認した。発走前オッズがある単勝・馬連についても、締切から確定
までの変動の大きさを測った。結果は購入方策の採用判断ではなく、その前提を確かめる記録である。

## 保存されているオッズ

対象snapshotは`098ce3f4b5d7480282269218d80cef05`である。

| 券種 | 発走前の時系列 | 確定オッズ | 確定払戻（NL_HR_PAY） |
| --- | --- | --- | --- |
| 単勝・複勝・枠連 | `ARCHIVE_O1_ODDS_TANFUKUWAKU`（2003-10-04以後） | `NL_O1_ODDS_TANFUKUWAKU`（1993以後） | 1986以後 |
| 馬連 | `ARCHIVE_O2_ODDS_UMAREN`（2003-10-04以後） | `NL_O2_ODDS_UMAREN` | 1986以後 |
| ワイド | なし | `NL_O3_ODDS_WIDE`（1999以後） | 1986以後 |
| 馬単 | なし | `NL_O4_ODDS_UMATAN` | 1986以後 |
| 3連複 | なし | `NL_O5_OddsSanrenInfo`（2002以後） | 1986以後 |
| 3連単 | なし | `NL_O6_OddsSanrentanInfo`（2004以後） | 1986以後 |

`NL_O1`〜`NL_O6`の`headDataKubun`は`5`（確定）と`9`（中止）だけで、`HappyoTime`は
`00000000`である。発走前の時系列は、過去分を取得できるDataSpecが`0B41`（O1）と
`0B42`（O2）に限られるため、ARCHIVEにはこの2表だけがある
（[ADR-007](../decisions/ADR-007-archive-realtime-odds-for-training-and-inference.md)）。
現行の`realtime`設定も`0B31`/`0B32`だけを取得する（`configs/jvlink.toml`）。
ワイド以降の券種の発走前オッズを過去に遡って得る経路はない。今後の分を保存するDataSpecが
`0B33`〜`0B36`であるかは、JV-Data仕様書でTo confirmとする。

## 測定条件

- 対象は中央01〜10場の全レースである。補正の当てはめに2023年、評価に2024〜2025年を使い、
  評価期間のレースは6,924件、単勝の確定オッズがあるレースは6,909件である。
- 締切（freeze）は保存された`NL_RA_RACE.HassoTime`の5分前とした。発走予定時刻が当時も
  有効だったという仮定は[参考接続手順](reference-real-input.md)と同じである。
- 締切時点のオッズは、`headDataKubun=1`の中間発表のうち`HappyoTime`が締切以前で最新の
  ものとした。締切との差は中央値1分、最大2分である。単勝の締切時点オッズは評価期間の
  6,912レースで得られた。
- オッズは4桁・6桁・7桁の整数を10で割る。0以下と数字以外（取消記号など）は欠損とし、
  比較から外した。

### 推定方法

単勝オッズ`O_i`から市場確率`q_i = (1/O_i) / Σ_j(1/O_j)`を作り、次の2通りで組合せ確率を出した。

- Harville型: 1着を`q`、2着・3着を残りの馬の`q`の比で選ぶ。
- Benter補正型: 2着を`q^γ`、3着を`q^δ`の比で選ぶ。`γ`と`δ`は2023年の600レースで、
  確定時の単勝から確定時の3連単を推定した誤差が最小になる格子点を選び、`γ=0.8`、`δ=0.7`とした。

3連複は6通りの着順の和、馬連は1・2着の2通りの和、ワイドは2頭がともに3着以内に入る確率である。
推定オッズは`(1 − 控除率) / P`とし、控除率は馬連・ワイド22.5%、3連複25%、3連単27.5%とした。
さらに2023年のデータで`log(実オッズ) = a + b·log(推定オッズ)`を当てはめた（重みは`1/実オッズ`）。
以下の表は、この補正後の値である。ワイドは確定時の下限・上限の幾何平均と比較した。

### 指標

誤差は`log(推定オッズ / 実オッズ)`で測る。

| 指標 | 意味 |
| --- | --- |
| 誤差の中央値 | 絶対値の中央値を百分率に戻した値 |
| ±10%以内 | 推定が実オッズの±10%以内に入った組合せの割合 |
| 20%以上過大 | 推定が実オッズより20%以上高い割合。推定を信じると期待値+20%以上に見える組合せにあたる |

## 結果

### 構造の誤差（確定時の単勝 → 確定時の各券種）

締切後の変動を含まない、この推定方法で到達できる下限である。Benter補正型の値を示す。

| 券種 | 組合せ数 | 誤差の中央値 | ±10%以内 | 20%以上過大 |
| --- | ---: | ---: | ---: | ---: |
| 3連単 | 16,135,474 | 44.8% | 14.2% | 33.0% |
| 3連複 | 2,703,515 | 42.0% | 14.9% | 30.8% |
| 馬連 | 631,311 | 28.1% | 21.2% | 28.0% |
| ワイド | 631,311 | 26.2% | 22.5% | 23.7% |

Harville型では3連単56.5%、3連複44.9%、馬連28.0%、ワイド27.5%であった。
Benter補正型による改善は3連単で大きく、馬連・ワイドではほとんどない。

### 実際に使う場合の誤差（締切時点の単勝 → 確定オッズ）

購入判断で使える情報から推定した場合である。補正も締切時点の単勝で2023年に当てはめた。

| 券種 | 誤差の中央値 | ±10%以内 | 20%以上過大 |
| --- | ---: | ---: | ---: |
| 3連単 | 56.5% | 11.6% | 25.7% |
| 3連複 | 53.3% | 12.2% | 24.4% |
| 馬連 | 36.3% | 17.0% | 21.0% |
| ワイド | 32.8% | 18.6% | 19.7% |
| 的中した3連単（6,909件） | 30.1% | 20.3% | 37.5% |
| 的中した3連複（6,909件） | 28.0% | 21.1% | 35.3% |

的中した組合せは、`NL_HR_PAY`の払戻を100で割った値と比較した。

実オッズの帯ごとの3連単の誤差の中央値は次のとおりである。

| 実オッズの帯 | 組合せ数 | 誤差の中央値 | 20%以上過大 |
| --- | ---: | ---: | ---: |
| 10倍未満 | 545 | 22.2% | 51.7% |
| 10〜100倍 | 136,685 | 23.2% | 39.0% |
| 100〜1000倍 | 1,708,369 | 30.4% | 29.1% |
| 1000倍以上 | 14,289,875 | 62.2% | 25.2% |

### 締切から確定までの変動（実オッズ同士）

| 対象 | 比較数 | 誤差の中央値 | ±10%以内 | 帯ごとの誤差の中央値 |
| --- | ---: | ---: | ---: | --- |
| 単勝 | 94,709 | 19.5% | 30.0% | 10倍未満9.3%、10〜100倍18.9%、100倍以上49.9% |
| 馬連 | 631,311 | 20.9% | 22.5% | 10倍未満7.9%、1000倍以上32.2% |

`log(締切時点 / 確定)`の中央値は単勝−0.111、100倍以上の単勝で−0.404であった。
長めのオッズほど、確定時に締切時点より上がる（市場確率が下がる）。

締切時点の単勝から締切時点の実馬連を推定した場合の誤差の中央値は33.1%で、
馬連の締切後の変動（20.9%）より大きい。

## 解釈

- 単勝からの推定は、3連単・3連複・ワイド・馬連のいずれでも期待値の判断に使える精度に
  達していない。期待値の閾値として想定する+10〜20%に対し、構造の誤差だけで26〜45%ある。
- 的中した組合せで推定が過大に出る傾向がある。的中した3連単の37.5%で推定が20%以上高く、
  バックテストの回収率を見かけ上よく見せる方向の偏りになる。
- 発走前の実オッズがある単勝・馬連でも、締切後の変動は誤差の中央値で約20%ある。
  期待値の判断には、締切時点のオッズから確定オッズを予測する補正が別に必要である。

## 制約

- 推定方法はHarville型とBenter補正型の2種類、補正は対数線形の1本だけである。
  複勝オッズの幅や馬連の時系列を制約に加える方法は試していない。
- `γ`と`δ`は3連単の誤差で選び、他の券種にも同じ値を使った。
- 締切は保存された発走時刻に基づく。発走時刻の変更前の値は使っていない。
- 発表時刻は記録された`HappyoTime`であり、当時の受信時刻を示すものではない。

## 加工と対応関係

`data/raw/race.db` の `NL_O4_ODDS_UMATAN` 表 → `data/processed/snapshots/81806ba398bb4fbe9a92eb1dbb75806f/NL_O4_ODDS_UMATAN.parquet`。
全列を同名・同順で保存し、SQLiteの文字列値と`NULL`をParquetの`string`/`NULL`として書き出す。
空白・日付風の値を置換せず、行の除外、結合、重複除去、集計、日時解析、欠損補完は行わない。
